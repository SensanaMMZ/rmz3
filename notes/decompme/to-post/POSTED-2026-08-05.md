Context recipe used (works with the decomp.me agbcc preset):
1. `cpp -I tools/agbcc -I tools/agbcc/include -iquote include -nostdinc -std=gnu89 -DMODERN=0 -P`
   over a file containing just the target .c file's `#include` list.
2. Append the macros the preprocessor drops: FALLTHROUGH, MOTION,
   SET_ENTITY_ROUTINE / SET_ENEMY_ROUTINE / SET_WEAPON_ROUTINE
   (see `$S/dm/macros.h`), plus `#define NULL ((void*)0)` and any
   `ENTITY_*` constants the function uses.
3. Append the file-local statics as bare declarations
   (`static const struct Collision sCollisions[N];`).
4. Verify locally before posting: concatenate context+source, run through
   `cpp -P` then agbcc with `-mthumb-interwork -Wimplicit -Wparentheses -O2 -fshort-enums`.
